# ✈️ Airline Reservation System

A Java-based Airline Reservation System designed to manage flight information, passenger details, seat reservations, cancellations, transactions, and administrative flight management.

## 📌 Project Overview

The **Airline Reservation System** is a console-based Java application developed to simulate the basic operations of an airline reservation system.

The system allows passengers to search and reserve flights, select seats, manage passenger information, and handle reservations and transactions. An administrator can manage flight information and view system reports.

## 🚀 Features

### 👤 Passenger Management

* Enter passenger information
* Manage passenger and guardian details
* Store passenger information for reservations

### ✈️ Flight Management

* View available flights
* Manage flight information
* Specify source and destination
* Specify departure date
* Specify flight timing
* Manage available seats

### 💺 Seat Reservation

* Display seat patterns
* Select available seats
* Reserve seats
* Track seat availability

### 🧾 Reservation Management

* Create reservations
* Cancel reservations
* Maintain reservation information

### 💳 Transaction Management

* Calculate reservation amounts
* Maintain transaction information
* Track total transaction amount

### 👨‍💼 Admin Management

* Admin login
* Create flights
* Delete flights
* View available flights
* Manage flight-related information

### 📊 Reports

* Display reservation information
* Display booking information
* Display cancellation information
* Display revenue information

## ▶️ How to Run

### 1. Clone the Repository

```bash
git clone https://github.com/YOUR-USERNAME/Airline-Reservation-System.git
```

### 2. Open the Project

Open the project in **IntelliJ IDEA** or another Java-compatible IDE.

### 3. Open the `src` Folder

Navigate to:

```text
src/
```

### 4. Run the Main Class

Run:

```text
AirlineReservationSystem.java
```

The application will start from the main class and display the system menu in the console.
